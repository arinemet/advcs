Design a grid map that is a 10 by 10 using a hash table.  Each grid location can contain multiple things.  The key will be of the Location class and the value of the GridObject class.

The Location class contains row and column positions in the grid.  The hashCode is calculated from the row and column.  The equals method is based on the values of the row and column. 

The GridObject class will contain the name of the item and a drawMe(Graphics,int,int) that will draw the item at a given location.  Gid objects backgrounds are water, dirt, sand, and grass.  Then include a tree (green circle with a brown rectangle) and a boulder (gray circle).

GridObject boulder = new GridObject("boulder");
